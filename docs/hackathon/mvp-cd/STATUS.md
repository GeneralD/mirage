## 最近の決定

- ワークツリーに隔離されたセッションのサブエージェントは、別のワークツリーに `EnterWorktree` で入れない。書き込み先のワークツリーには、先にメインセッションが入っておく（#538）
- テストを付けない契約では、定型の「Interface の各項目に単体テスト」を Done に残さない。View の `body` を評価するテストは書かない（#228、#478）
- 置き換えた PR は、`-r1` の PR を開いた worker が閉じる（#442）
- worker の gate は切り離して起動し、制限時間のある呼び出しで待つ。worker は 5 並列、gate slot は 3（run 3 の全滅から）
- 失敗は契約の修理と 1 回の再投入で扱い、worker のモデルは上げない（DECISIONS `[run]`）
